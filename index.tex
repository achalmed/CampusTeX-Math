%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
 
 % El primer comando que siempre tendrás declarará la clase de tu documento. Esto le dice a LaTeX qué tipo de documento estás creando (artículo, presentación, póster, etc.). 
% \documentclass es el comando
% En {} especificas el tipo de documento
% En [] defines parámetros adicionales

\documentclass[a4paper,10pt]{article} % Esto define el estilo de tu papel (twocolumn)

% Por lo general, utilizamos el tipo de artículo. Los parámetros adicionales son el formato del papel en el que deseas imprimirlo y el tamaño de fuente estándar. Para nosotros, esto es a4paper y 12pt.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% 2. Paquetes
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

% Los paquetes son bibliotecas de comandos que LaTeX puede utilizar al compilar el documento. Con los comandos especializados, puedes personalizar el formato de tu documento.
% Si los paquetes que llamamos aún no están instalados, TeXworks te pedirá que instales los paquetes necesarios durante la compilación.

% Primero, por lo general, queremos establecer los márgenes de nuestro documento. Para esto, utilizamos el paquete geometry. Llamamos al paquete con el comando \usepackage. El paquete va entre {}, los parámetros van entre [].
\usepackage[top = 2.0cm, bottom = 2.0cm, left = 2.5cm, right = 2.0cm]{geometry} 

% Desafortunadamente, LaTeX tiene dificultades para interpretar las letras especiales alemanas (Umlaute). Las dos siguientes líneas y paquetes deberían ayudar. Si no funcionan para ti, avísame por favor.
\usepackage[T1]{fontenc}
\usepackage[utf8]{inputenc}

% Los dos siguientes paquetes, multirow y booktabs, son necesarios para crear tablas con un aspecto agradable.
\usepackage{multirow} % Multirow es para tablas con múltiples filas en una celda.
\usepackage{booktabs} % Para tablas aún más bonitas.

% Como generalmente queremos incluir algunas gráficas (archivos .pdf), necesitamos un paquete para eso.
\usepackage{graphicx} 

% La configuración predeterminada de LaTeX es sangrar nuevos párrafos. Esto es útil para artículos, pero no es muy agradable para conjuntos de problemas o tareas. El siguiente comando establece el sangrado en 0.
\usepackage{setspace}
\setlength{\parindent}{0in}

% Paquete para colocar figuras donde desees.
